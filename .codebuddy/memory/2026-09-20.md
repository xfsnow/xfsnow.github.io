## 英文首页 Tools 显示中文的根因与修复
- 症状：英文首页 `en/index.html` 的 Tools 板块显示中文（GeoGebra手册中文版 等）。
- 排查：`en/tools.json` 内容本身已是英文、与 `zh/tools.json`（中文）结构一致（id/icon 相同，仅语言不同；zh 用绝对路径 `/geogebra/`，en 用相对路径 `../geogebra/`，解析后等价）。
- 根因：`assets/template/index.html` 的 Tools 区块（`<div class="tools-grid">` 内 6 张卡片）是**写死的中文**，模板完全没有使用 `BlogMaker.make_home` 加载进来的 `data.tools`，所以无论 tools.json 是什么语言，生成的 HTML 都是中文。
- 修复：把模板中写死的 6 张卡片改为 `{% for tool in data.tools %}` 动态渲染（标题/描述/链接取自 tools.json，各工具原有内联 SVG 图标按 id 映射保留，不改变外观）。
- 重新执行 `python BlogMaker.py` 重新生成中文（`index.html`）和英文（`en/index.html`）首页及全站页面，验证 ok。
- 约定（再次确认）：`index.html` 与 `en/index.html` 等 HTML 均由 `BlogMaker.py` 基于 `assets/template/` 模板 + `{zh,en}/tools.json`、`{zh,en}/index.js`（articles）生成。**不要直接手改生成的 HTML**，应改模板/数据源后用脚本重新生成。
